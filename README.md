# Two Buds Dispensary — redesign preview

A design preview of a proposed redesign of [twobudsdispensary.nyc](https://twobudsdispensary.nyc/). It is **not the live site**: menu prices and deals are a snapshot of the live menu on Nov 5, 2026, and every Order / Shop button opens the live Two Buds menu.

**Preview:** https://sgen-sites.github.io/twobuds-preview/

- Static HTML, CSS and JavaScript; no build step on GitHub. Pages serves this branch as it is.
- Every page carries `<meta name="robots" content="noindex, nofollow">` so search engines leave the preview alone. It is not password-protected.
- 1,403 pages: the shop hub and its categories, 1,150 product pages, 189 brand pages, deals, visit and delivery pages, the strain library, the blog and the company pages.
